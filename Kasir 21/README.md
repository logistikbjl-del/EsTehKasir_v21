# Es Teh Kasir v2.1

Aplikasi kasir Android offline untuk satu toko.

Fitur:
- Kasir dan keranjang
- Es Teh Jumbo, Es Jeruk, Matcha, Thai Tea, Green Tea
- Pencarian produk
- Kelola produk dan stok
- Struk transaksi dan bagikan struk
- Nama toko
- Tanggal dan jam transaksi
- Laporan harian
- Riwayat transaksi
- Backup/bagikan data
- Scroll halaman
- Tombol kembali internal
